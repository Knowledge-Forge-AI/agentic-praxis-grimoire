# Shiori

Shiori is APGR's original adult high-elf mascot: dark-purple hair, dark-blue eyes,
purple/blue/silver scholar robes, and an enduring fascination with grimoires.
The `shiori.webp` illustration was created with the built-in image-generation
tool and exported as an optimized transparent website asset.

This new illustration and organizational brand assets are excluded from the
AGPL grant. No separate artwork license is granted here; applicable rights are
reserved. APGR's software and documentation retain their existing terms.
