Know the boundaries.

APGR is an early pilot. Static context is the default; adaptive projection is experimental and opt-in.

The portable CLI supports Apple Silicon macOS and Linux AMD64 / ARM64. Follow the distribution notes for installation-specific requirements. No token or context-window saving is claimed.
