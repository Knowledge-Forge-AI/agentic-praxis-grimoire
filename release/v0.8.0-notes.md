# Agentic Praxis Grimoire v0.8.0 (release candidate)

Status: candidate only. This document describes the bounded v0.8.0 candidate;
v0.8.0 has not been publicly published.

v0.8.0 adds the provider-neutral `footprint` package and its deterministic
context-footprint, comparison, and projection records. The candidate uses the
following versioned identities:

- `apg.context-footprint/v1`;
- `apg.context-comparison/v1`;
- `apg.context-projection/v1`;
- `apg.context-component-registry/v1`; and
- `apg.capacity-control-mapping/v1`.

Canonical records use strict UTF-8 JSON, deterministic ordering, integer
metrics, explicit availability, and domain-separated fingerprints. Unknown
versions, fields, mappings, evidence, and incompatible units fail closed.
Missing or unavailable measurements are explicit and are never represented as
zero. Projections retain their canonical source identity and refuse
consequence-bearing omissions or sensitivity and retention downgrades.

The historical 9,527-byte skill-description integrity control is retained.
Discovery descriptions, semantic bodies, support material, and fully
materialized bundles remain separately measurable. No new skill candidate is
included in this candidate, and the optional external diagnostic importer is
deferred until its format, provenance, licensing, fixture, safety, and
consumer-value gates are independently met.

The v0.8 publication packet preserves the ten-asset distribution shape:

1. one distribution manifest;
2. one `SHA256SUMS` file;
3. three platform Python wheels;
4. one normalized Python source distribution;
5. three platform npm packages; and
6. one npm launcher package.

The exact filenames, bytes, and hashes are produced from the reviewed source
and the public v0.7.0 base. Publication occurs only after the dispatcher-owned
pre-final review and dispatcher Git finalization, followed by fresh GitHub,
Go-module, PyPI, and npm readback. A prepared candidate or local artifact is
not a release.

The npm packet includes a fail-closed negative metadata check. Candidate and
fresh registry metadata must contain no private checkout reference, absolute
local path, development-only identity, credential, or mutable local source
reference, including in `_resolved` or `_from` fields when present. Any
violation stops publication and invalidates the affected readback.

Nix is not a v0.8 release artifact or activation path. Nix participation is
limited to a read-only consumer handoff and qualification record; it does not
activate a host, mutate `.flakes`, install APGR globally, or gate the
first-party release path.
