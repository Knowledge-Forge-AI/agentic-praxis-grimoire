# Component task requirements

Build a small task list for a user who cannot rely on pointer input alone.
The rendered view must expose three initial items from the local data below,
show the selected item clearly, support keyboard movement and selection, and
show an explicit empty state after the final item is removed.  The user should
be able to tell which action is available from the rendered labels and focus
state.
