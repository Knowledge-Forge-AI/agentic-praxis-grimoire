# v0.10 Browser/UI verification architecture

APG123 implements the Browser/UI slice under the original authorized scope.
The producer amends the bound proposal to incorporate advisory plan-review
findings. Neither the proposal nor those findings expands phase authority.
The dispatcher owns independent checkpoints and final closeout.

## Ownership

| Owner | Decision surface | Excluded surface |
| --- | --- | --- |
| SVG | Vector authoring, coordinates, paint, reuse, serialization and resource context | Runner mechanics and accessibility audit conclusions |
| Playwright Test | Selected runner/config, fixtures, locators, waiting, execution and artifacts | Accessible standards and general DOM/runtime semantics |
| Web accessibility | Native/ARIA meaning, interaction obligations and evidence hierarchy | Automation implementation and SVG geometry |
| Future browser-runtime | Reserved browser/DOM/runtime semantics | No implementation or implicit loading in APG123 |

Existing CSS, JS, TS, JSX, React and Node contracts remain independent. No Vite
or npm package-manager profile is admitted. Explicit resolver composition does
not extend the structured-fact vocabulary or load adjacent owners automatically.

## Capacity and package contract

Current `v0.10-browser-ui` admission requires the exact original 39 identities
plus SVG and the two Browser/UI leaves: 42 canonical/catalog/projection/discoverable
leaves, 14 stable and 28 provisional. Original descriptions and SVG's description
are conserved byte-for-byte. Each candidate has at most 330 UTF-8 description
bytes; current ceiling is 10,517. The six-name reservation remains 11,507 and
unused allowance cannot transfer between identities. Historical policies retain
their own 39/40 validation but cannot satisfy current admission.

Go selects the policy through code constants; Python reads the strict selector.
Parity is therefore constant/behavior-level, not shared selector-file loading.
SVG retains its existing 20,480-byte body rule. The two new profiles receive no
new numeric body ceiling; measured metadata and caller context budgets still apply.

## Runtime and evidence boundary

The exact consumer-selected Playwright Test 1.62.1 package is installed only in
owned external scratch. Browser binaries are either reused read-only or downloaded
into owned scratch/cache. No engine/channel substitution can close an unavailable
required Chromium, Firefox or WebKit lane. Explicit prerequisites refuse missing
or wrong packages, runtime identity, scratch custody and executables before tests.

Pytest owns the maintained integration entrypoints, which invoke the real browser
matrix; the canonical combined gate therefore includes those lanes. The harness
serves only APGR synthetic loopback fixtures, rejects untrusted network resources,
blocks service workers and creates fresh contexts. Actual Playwright Test child
runs exercise discovery, fixtures, failure retention and SIGINT interruption.
Sanitized receipts outlive temporary profiles; artifact retention is explicit.

SVG01 uses inline SVG in an HTML document with an expressly permitted same-origin
external `<use>` sprite. It observes both browser fetch and changed rendering.
SVG02/SVG03 pair forbidden origin/path controls. These do not claim external
resource support in secure static image mode. APG122's historical eighteen
semantic/six navigation-only classification is preserved; browser corroboration
is additive and does not rewrite the SVG leaf's ownership.

Accessibility evidence covers representative names, structure, focus, SVG purpose,
state, live content and semantic snapshots. It does not establish screen-reader
announcements or WCAG conformance. Engine-specific focus pixels are expected
variance; contrast and usability need their own rendered/manual evidence.

## Consumer and lifecycle boundary

Theme Forge is read-only evidence. Disposable-copy execution preserves its lock,
thresholds and baselines; an occupied fixed port is a limitation, not authority
to terminate another server. Consumer findings cannot substitute for the APGR
three-engine matrix. Current results belong in the APG123 evaluation.

Rollback removes the two new admissions and their integrated surfaces together,
restoring SVG-only current admission while preserving SVG and historical records.
No public v0.10 release, consumer/host mutation, successor work or independent
review acceptance is authorized by this document.
