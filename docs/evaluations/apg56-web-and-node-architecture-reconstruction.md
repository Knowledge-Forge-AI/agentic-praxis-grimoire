# APG56 Web and Node Architecture Reconstruction

## Scope and outcome

APG56 reconstructs the ten-candidate Web and Node profile family from
first principles on APG52's exact-object, two-run-reproducible evidence.
It starts from the exact verified APG55 mainline object and its complete
managed report, and it is a fresh phase:
[ADR 0031](../adr/2026/07/0031-web-and-node-profile-family-ownership-and-authoring-sequence.md)
remains **Rejected** and is not reopened, amended, or repaired into
acceptance. The result is **Complete**: fresh Web and Node owner
architecture reconstructed from reproducible evidence;
[ADR 0034](../adr/2026/07/0034-web-and-node-profile-family-reconstruction-and-authoring-sequence.md)
is **Proposed**; authoring remains pending independent review. No skill
was authored or integrated.

## Growth architecture

A method freeze
(SHA-256 `df31de680ba3d82a015f4bc982bbf9e878e11d5709a8ef79cf5dd68f117fc72b`)
fixed the complete family-balanced derivation rule before calculation;
a deterministic standard-library tool applied it to hash-verified
compact inputs with byte-identical repeat runs and no post-result
tuning. Eight classes receive proposed exact bands
(JavaScript module 399/1061/3402; TypeScript module 180/1604/1942;
handwritten declaration 140/890/1453; TypeScript configuration
10/25/26; Node runtime/CLI 174/861/1462; CSS stylesheet 133/663/929;
Markdown document 164/1432/3474; Astro component 133/169/390). Scoped
CSS (no corpus), standalone JSX/TSX (two families, zero target
artifacts), and MDX (76.6% single-family concentration) remain
non-normative with no manufactured measurement. All ten declared
acceptance tests pass, family imbalance and anchor concentration are
disclosed in sensitivity evidence, and the unchanged APG51 hypotheses
are compared row-by-row without claiming reproduction of their
unrecovered rule. Mixed `.tsx`/`.mdx`/`.astro` files stay one-count
hosts, embedded CSS is non-additive, generated-artifact exclusions are
inherited, and a legacy smallest-safe-fix rule prevents forced
refactoring. Semantic risk remains a separate axis that never reduces
to size.

## Policy and adjacent gaps

React and Vitest retain ADR 0029 Policy A: configuration-only React
presence and total Vitest absence at the exact pinned snapshots are not
behavioral dogfood, so both are `defer-policy` with the exact
evidence-change conditions recorded; no external or synthetic dogfood
path was taken. Browser/DOM runtime, generic HTML semantics, and
accessibility are recommended for separate future evidence phases and
are never silently absorbed; Starlight, package managers,
bundlers/Vite, lint/format, deployment, visual design, browser support
policy, and content strategy remain project-owned. No mandatory skill chain exists
anywhere in the proposed graph.

challenges, source/version/rights boundaries, semantic-risk
