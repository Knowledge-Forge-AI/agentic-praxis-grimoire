# APG88 MDX and Astro Profiles Complete the v0.6 Authoring Set

## Candidate result

APG88 accepts ADR 0050 with amendment and provisionally integrates exactly
`mdx-profile` and `astro-profile`. Candidate development is 39 canonical
skills, 39 catalog rows, 39 exact relative projections, and 39 discoverable
entries, with 14 stable and 25 provisional rows and zero malformed metadata.
Dispatcher-owned pre-final review remains external and is not self-attested.

## Profile boundaries and source basis

MDX owns the document/component seam: Markdown-to-JSX transitions, imports and
exports, expressions, provider mapping, and MDX-specific compile/runtime
distinctions. Exact MDX 3.1.1 object
`50aa8df0b027c893dec9f97a2b7c51539e9f1a4b`, released 2025-08-29, and official
MDX documentation main object `685627a819567c0788eadb85f5f57065bcc81c2c`
were inspected on 2026-08-20. The sources are MIT-licensed.

Astro owns framework, project, content, route, island, directive, and execution
placement. Astro 7.1.6 annotated tag
`adbb7cbd12c47a869ad5008688209152e2362849`, commit
`9865d1c03af6d1a1f15c9811858778cc952ca4e4`, released 2026-07-29, and official
docs object `ad92aec16358fee8e85f0dcd3b1e6baa9fd039c8` were inspected on 2026-08-20.
The repositories are MIT-licensed. Both profiles are independently written;
APG copies no upstream prose, code, examples, tables, or diagnostics.

Mutable docs and integrations require refresh before behavior-bearing
correction, maturity review, or publication when MDX compilation/provider
behavior or Astro components, directives, collections, routing, modes,
adapters, or integration hooks materially change.

## Objective boundary evidence

The APG88 public-safe fixture assigns every required positive and non-trigger
case to one exact owner. MDX retains only the document/component seam. Markdown,
JSX, React, TypeScript, JavaScript, and Astro retain their independent regions.
Astro retains `.astro` execution, islands, directives, server/client placement,
collections, routes, project conventions, and integration configuration.
React, MDX, JSX, TypeScript, Node, and project-owned Vite, Starlight, styling,
accessibility, and deployment concerns remain outside.

Markdown now routes whole-file MDX work to the installed `mdx-profile`, and the
APG87 JSX/React leaves route to both installed siblings rather than describing
reserved absent owners. No leaf silently invokes or reproduces another.

## Limitations and stop

This phase validates reusable APG guidance and APG-owned fixtures. It does not
execute a target MDX compiler or Astro application, mutate a target or active
projection, establish arbitrary project versions, or prove browser, hosting,
accessibility, or deployment behavior.

No APG89, readiness, version advance, release publication, deployment,
advisory discovery, provider staging, commit, or push is authorized or
performed.
