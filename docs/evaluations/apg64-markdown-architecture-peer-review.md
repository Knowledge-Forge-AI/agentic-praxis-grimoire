## Evidence and amendments

Exact CommonMark 0.31.2 and GFM 0.29 objects and rights were independently
reverified. The accepted hierarchy uses the actual renderer/parser and
configuration as effective grammar, CommonMark 0.31.2 as a bounded base
reference, GFM 0.29 as a bounded reference for its five specified extension
families, and version-bound implementation differences as
`parser-tool-owner` facts. It does not invent a formally specified hybrid or
equate GitHub rendering with Astro/Starlight/Satteri rendering.

The target inventory is nineteen tracked Markdown paths, not a canonical set
of seven: three maintained, one generated, three tool-boilerplate, seven
fixture/demo, three legal/governance, one agent instruction, and one symlink.
The expanded inventory adds useful boundary and purpose dogfood but no
long-document pressure or numeric-threshold authority. No target command ran.

The corrected 36-row register separates selection, ordered response severity,
and exact receiving owner; gives every row one unconditional primary decision
and owner; and types rows 035–036 as review-process invariants rather than
candidate semantics. Fourteen qualitative structural signals now record
evidence class, decision scope, response, route, and false-positive control.
Disposition C remains qualitative, line count remains descriptive, and
`whole-document-review-boundary` closes indefinite unreviewable growth without
inventing numeric bands.
