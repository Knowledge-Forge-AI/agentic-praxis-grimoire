not a native-host workbench. Service workers are blocked. Actual Tauri WebView,
sidecars, real project data, full accessibility and OS-level network isolation are
outside this evidence. Static committed path inspection covers SVG naming and
viewBox, React/browser object-URL and timer cleanup, and Vite/npm ownership seams.

Later live checkout observations show both commit and worktree drift; attribution
is unknown. Qualification remains bound to the earlier committed export and does
