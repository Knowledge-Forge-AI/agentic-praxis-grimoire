dispatcher finalization remains separate.

## Scope

Repair native evidence discovery so packaged source fixtures are inert while
exact authority paths, schemas, duplicate-copy bindings and tree-wide link
refusal remain enforced. Retire automatic package publication on release
events and provide a tree-bound, no-rebuild attended GitHub release verifier.

publication or local binary build.

## Verification boundary

The baseline duplicate-key failure was reproduced using the repository's exact
classification fixture inside a synthetic extracted sdist. Closeout reproduced
the postmerge failure with removed synthetic commit access, then passed the
integrated focused Python selection: 446 cases. This includes the complete
fixture lifecycle through the published audit, missing premerge association,
changed postmerge association, and captured-run/commit tamper rejection.
Scoped Ruff, topology, inventory and policy consistency checks pass.
These checks do not prove hosted qualification, governance configuration or
release publication. actionlint, zizmor and actual historical artifact replay
remain unverified. Exact commands and limitations belong to the phase's
excluded verification record. Terminal amendments were not independently
re-reviewed; the supplied review preceded those bytes.

The historical native run's artifacts remain listed by GitHub. Local retrieval
was denied by the sandbox network boundary, so replay of the actual hosted
evidence remains unverified. No historical replay is a fresh RC gate pass.
