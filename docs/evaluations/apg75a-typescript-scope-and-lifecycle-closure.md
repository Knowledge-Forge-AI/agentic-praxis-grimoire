## Clean-runner contract

The repository uses disposition B: when the validated inventory owns
compiler-backed TypeScript tests, the standard runner requires an absolute
regular executable outside the checkout named by `APG_TYPESCRIPT_TSC`, rejects
symlinks and checkout-local executables, and verifies exact output
`Version 7.0.2`. It fails once with an actionable prerequisite error before
creating test or coverage artifacts when the binding is missing, unsafe,
non-executable, wrong, or malformed. The runner does not install from the
network and does not vendor TypeScript. Historical and rollback inventories
without those owners remain compiler-independent. Exact scratch-bound compiler
execution remains required for current unit, integration, combined, and release
qualification.
