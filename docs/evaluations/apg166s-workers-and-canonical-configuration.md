## Scope and proposal disposition

The original assignment owns standalone APGR workers, a coherent APGR-home
dispatcher bundle, the standard five-parent `gemini_sub` roster, worker-qualified
dynamic routing, four observed worker canaries, and provider-free D1
carry-forward. The disposable bootstrap controller is read-only dispatch
infrastructure and is not product qualification evidence.

Proposal disposition: **amend**. The supplied plan remains the implementation
basis with the following dispositions of its independent review findings:

1. Adopt captured-bundle launch authority. Model and effort selection must reach
   provider arguments, external leaves and native bindings from that snapshot.
   Source profile files are defaults or posture owners, not competing runtime
   model authorities. An operator override requires launch-path evidence.
2. D1 carry-forward must cover its isolated launch and home semantics, not only
   `build_argv`. Historical exact-source evidence cannot qualify changed source.
3. Adopt option A only: add an Opus role for Opus 5.5 and preserve the historical
   `primary` role's Opus 5 model. No live native Read probe is authorized here.
4. APGR owns its worker entrypoints and guidance. Entrypoints resolve absolutely
   within the selected candidate. The emergency dispatcher retains separate
   configuration and is selected only by an operator, with no automatic failover.
5. Native worker use requires actual admission or subagent-event evidence.
   Requested model values must never masquerade as effective observations.
6. The Astra canary uses `implementation-testing` at medium effort with an
   explicit read-only launch. Canaries must enter the real dispatcher launch
   path and retain candidate entrypoint identities, authority and cleanup.
7. Absent optional bundles may use source defaults; incomplete or legacy bundles
   require explicit migration. Tests and canaries use isolated APGR homes.
8. Retain the legacy catalog schema identifier for compatibility in this tranche;
   its spelling grants no external runtime authority. Complete coherent source
   and provider-free gates before attempting the bounded live canaries.

The roster applies to all three existing phase types. The producer reported no supplied earlier
stage deltas; closeout dispositions the cumulative product delta. Internal workers are implementation evidence, not either of the
two dispatcher-owned independent review checkpoints.
