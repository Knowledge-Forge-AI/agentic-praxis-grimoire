# APG51 Web and Node Architecture Peer Review

Phase ID: `APG51`

Evaluation date: 2026-07-28

## Objective and inherited history

APG51 independently reviewed the APG50 web and Node profile-family
architecture. The complete APG50 recovery history was preserved: the
malformed authoring commit, its forward revert, and the formal APG50 design
commit remain distinct immutable objects. The exact Claude branch was
delivered and verified before this review branch was created from the formal
object. APG51 corrects and dispositions APG50 forward; it does not rewrite the
historical objects.

Both Knowledge Forge AI targets were re-inspected read-only at their exact
APG50 snapshots. Primary-source, version, rights, TypeScript-consumer, owner,
scenario, structural, privacy, and public/private claims were independently
reviewed.

## Initial correction result

One coherent correction pass produced:

- consumer-specific TypeScript evidence: the theme's TypeScript 5.9.3
  Astro-check consumer is verified, while the website's locked native 7.0.2
  package and bin have no verified tracked project/compiler-service consumer;
- separate semantic-risk and handwritten-growth axes;
- deterministic candidate thresholds for every proposed artifact class,
  one-count `.tsx`/`.mdx`/`.astro`, generated-artifact exclusions, and a
  legacy smallest-safe-fix rule;
- Policy A for React and Vitest;
- separate-future-evidence recommendations for browser runtime, HTML, and
  accessibility;
- project ownership for Starlight and tooling/deployment surfaces; and
- a CSS-only first-slice candidate.

All sixty APG50 scenario IDs remained unique, continuous, and assigned six per
candidate, with explicit semantic and growth dispositions.

## Corrected-state findings

Fresh non-author review found two material defects after that one pass:

1. the pinned canonical JSX repository states CC BY 4.0 in its README, but the
   corrected package falsely said it granted no reuse license; and
2. the structural corpus record was not reproducible: it contained abbreviated
   identities, aggregates, approximate percentiles, and no exact artifact
   inventory/sample rule while claiming exact reproducible evidence.

Exact rights and empirically reviewable threshold evidence are APG51 hard
gates. The phase's one-cycle rule prohibits repairing those material defects
into acceptance. [ADR 0031](../adr/2026/07/0031-web-and-node-profile-family-ownership-and-authoring-sequence.md)
is therefore **Rejected**.

The JSX factual record is corrected for future work: the canonical repository
redirect and pinned state identify the draft syntax specification, and its
README licenses the work under CC BY 4.0. No upstream or target expression was
copied into APG.

## Policy and adjacent gaps

React and Vitest remain Policy A deferrals under ADR 0029. Configuration-only
React presence and Vitest absence are not behavioral dogfood. Policy B or C
would require separate authority and an explicit ADR 0029 amendment.

Browser runtime, HTML, and accessibility remain recommended subjects for
separate future evidence phases. Generic HTML, browser APIs, accessibility,
package policy, build/deployment policy, visual design, and Starlight product
semantics are not silently absorbed by the ten candidates. No Starlight
profile is recommended.

## Slice, state, and boundary

There is no eligible or recommended Claude authoring slice after APG51.
CSS-only was the strongest initial candidate, but the corrected-state defects
prevent it from becoming authoring input. A fresh separately authorized
architecture phase must correct and independently verify the exact rights and
reproducible corpus package before slicing.

APG51 authored no profile leaf and changed no projection, catalog row, route,
maturity state, test owner, release row, dependency, fixture, or executable.
Development remains 28/28/28 with fourteen stable and fourteen provisional
skills. Public and active remain corrected v0.4.0. Target builds/tests,
package installation, browser/deployment work, skill authoring/integration,
and full APG executable suites did not run. No successor is authorized.
