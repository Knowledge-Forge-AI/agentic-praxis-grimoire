# SVG Language-Profile Specification

Lifecycle: `provisionally-integrated`.
Lifecycle ADR: `Proposed`.

APG122's [SVG contract](../architecture/v0-10-svg-language-profile.md) owns the
fifteen stable authoring clauses, source-to-clause provenance, ownership and
scenario boundaries. The [operational leaf](../../skills/svg-language-profile/SKILL.md)
applies those clauses to one consequence-bearing decision.

The synthetic scenario harness supplies bounded structural and mathematical
evidence. It does not establish browser rendering, accessibility trees or WCAG
compliance. Initial maturity is provisional; dispatcher review and closeout
remain pending. [ADR 0053](../adr/2026/09/0053-v0-10-discovery-capacity-and-svg.md)
owns capacity and explicit selection. No future leaf or release is authorized.
